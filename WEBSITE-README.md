# Zhuo Li — Academic Homepage

Personal academic website for Zhuo Li, PhD student at the National University of Singapore, inspired by https://github.com/luost26/academic-homepage.

## Edit your content

Edit `profile.js` to update your biography, interests, news, publications, education, email, and academic profile links. Bracketed text and the sample publication are placeholders. Set `placeholder: false` for real publications. Empty links stay hidden.

Edit `styles.css` to change the design. The downloadable CV template is `cv-template.md`; replace its link in `index.html` if you upload a PDF. Identity metadata and the initials are in `index.html`.

## Publish with GitHub Pages

1. Upload these files to your GitHub repository's root, including `.nojekyll`.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select **main** and **/ (root)**, then save.

For a personal site, name the repository `<your-github-username>.github.io`; its address will be `https://<your-github-username>.github.io/`. An ordinary project repository also works, at `https://<your-github-username>.github.io/<repository-name>/`.

No dependencies or build step are required. Changes to the publishing branch update the site automatically.

GitHub guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
